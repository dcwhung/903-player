用戶要求：一日未發佈，任何改動（圖、字、上下架）都可以還原返上次發佈嘅版本。掣放確認發佈頁時間線每行同編輯頁（喺原本編輯位）；一行多過一項改動就撳名入編輯頁逐項揀；從未發佈過嘅新內容唔出還原；所有還原掣紅色。

① 確認發佈頁 · 時間線每行加「還原」

每行最右「還原」= 還原成行（劇本身 / 某個短篇）。一行有多過一項改動，短篇名 / 「劇集」變 link，撳入編輯頁逐項揀。新短篇、新集數冇「還原」。

規則

還原去邊 上次成功發佈嘅版本（發佈 / 部署記錄「使用中」嗰個）
包括 文字欄位、圖（橫圖 / 碟面）、配色、上下架、短篇資料；節目同劇集都有
唔出還原 從未發佈過嘅新節目 / 新劇 / 新短篇；新集數（R2 掃描出嚟，用發佈剔格揀）
確認發佈頁 每行一粒「還原」（成行）；多過一項改動，名變 link 入編輯頁逐項揀
編輯頁 喺原本編輯位：欄位標題旁「已修改」+ 紅色「還原」；圖喺鉛筆旁加紅色圓掣；文字欄下面細字顯示已發佈嘅值；有未儲存改動時先唔准還原
顏色 所有「還原」掣都係紅色（--danger）
未定 確認發佈頁每張劇卡要唔要「全部還原」；未到期嘅排程下架算唔算可還原
還原之後 即刻寫入 D1，仍然未發佈；時間線 / 待辦即時更新；toast 提示
