P3 #4：內頁右邊把手

闊橫版 1300×800（--ui-scale 1.5），畫面縮細 0.6 倍顯示；底圖係 v1.22.2 現有內頁截圖。
已決定：只限闊橫版；只有「播緊（或暫停咗）嘅唔係呢頁嘅節目 / 劇」先出把手；把手用預留位（右邊 --home-handle-reserve），唔遮播放器；把手色跟播緊嗰個節目；播緊顯示「播放中」，暫停顯示「已暫停」（同主頁把手同一個 component）。撳把手 = 撳返回：返主頁，把手放大做右邊播放卡。

① 喺公子會頁播緊公子會：唔出把手

左邊播放器已經係播緊嗰樣，唔使把手；右邊預留位照留（闊橫版一直留，唱片大細唔會因為把手出 / 走而變）。返主頁 = 而家嘅行為：右邊播放卡（split）。

② 喺森美小儀系列頁，播緊嘅係公子會

左邊播放器係呢頁（森美小儀，未開始）；右邊把手話你播緊另一樣嘢，色跟公子會（深色），喺粉紅頁面上一眼分得出。
喺呢頁揀一個短篇開始播 → 變咗「喺自己頁播」，把手 fade out 消失（預留位照留，唱片唔變大細、唔移位），版面變返 ① 咁。

③ 暫停咗（或者喺主頁撳咗 ✕ 先入嚟）

同 P2 主頁把手一樣：muted 色「已暫停」。喺主頁撳 ✕ 閂咗卡再入內頁都係呢個樣；返主頁之後照舊係把手，唔會放大做卡。

④ 撳返回 / 撳把手：把手放大做主頁右邊卡

View Transition：內頁淡出，把手由右邊緣放大成主頁右邊播放卡（同主頁「把手 → 卡」嘅開返動畫一樣方向）。
冇嘢播（未載入任何嘢）或者播緊嘅係呢頁 → 內頁唔出把手，返主頁照舊。
