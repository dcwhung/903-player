⑧ 快將下架（新增，同 P8 一齊做）

⑤ drama.json schema 建議（未改真 schema，放最底）

而家 ArcDefinition 已經有 optional addedAt（用嚟計 14 日「新」）。建議直接用佢做上架日，唔加新欄位： 

"arcs": [
  { "name": "我心不死", "disc": "arcs/heart/disc.webp", "episodes": 37 },
  {
    "name": "XXX",
    "addedAt": "2026-11-12",          // 將來日子 = 即將上架；當日起自動變正常 + 「新」
    "disc": "arcs/xxx/disc.webp",     // optional，冇就用劇集碟面（灰咗）
    "episodes": 20                    // 知道就寫；唔知可以唔寫（見下）
  }
]
  • 判斷：addedAt > hkToday() = 即將上架；selector 一個 isArcUpcoming(addedAt, today)，同 isArcNew 放埋一齊
  • 上架時間：上架 = 香港時間 addedAt 當日 00:00（用戶已確認），即係 hkToday() >= addedAt 就當已上架，唔使寫時間
  • 未上架嘅集數：唔產生 SeriesEpisode（唔砌音檔 URL、唔 probe、唔入進度 / 收藏 / mini player / 續聽），只出一個 UpcomingArc { arc, addedAt, count? , disc? } 畀 UI
  • episodes 可以唔寫（用戶已確認）：只限未上架嘅 arc（arc 或劇集層有 addedAt）。一覽表「即將上架」行第二行淨係「11/12（四）上架」，唔出集數。parse 驗證：冇 episodes 就一定要有 addedAt（日子 parse 時驗唔到，因為會過）；到咗上架日仲未補 episodes → 繼續當即將上架 + console.warn，唔會出空短篇
  • 逐集上架：arc 加 optional episodeDates（集數 → 日子，即「呢集起」）： 
    { "name": "戀愛二分一", "episodes": 30,
  "episodeDates": { "11": "2026-11-19", "21": "2026-11-26" } }
    規則：key 要喺 arc 集數範圍入面、日子跟集數遞增、要遲過 arc addedAt；第 11 集起至下一個 key 之前都係 11/19。未到期嘅集數唔產生 SeriesEpisode，清單出灰行（UpcomingEpisode { no, date }）
  • 新一批集數嘅「新」：isArcNew 改用「arc addedAt 同已到期 episodeDates 入面最遲嗰個」計 14 日
  • 整套新劇（tile 必填，用戶已確認）：劇集層 addedAt 係將來日子 = 即將上架劇集，一登記即刻喺書架最尾出：主頁書架出灰格、撳唔到、唔出劇集頁（直接開 URL 就返主頁）；全部 arc 唔產生集數。daily 劇集而家冇劇集層 addedAt，要一併加落 DailyDefinition
  • 下架日（⑧）：三層都用同一個字眼 removedAt（同 addedAt 對稱，意思係「呢日 HK 00:00 起唔再提供」）： 
    { "name": "蘭茜夫人劇場", "removedAt": "2026-12-05",        // 成套劇
  "arcs": [
    { "name": "戀愛二分一", "removedAt": "2026-12-05",       // 短篇
      "episodeRemovedAt": { "1-5": "2026-12-05" } }        // 集數（單集 "3" 或範圍 "1-5"）
  ] }
    驗證：下架日要遲過上架日（劇集 / arc 嘅 addedAt、該集 episodeDates）；arc 嘅唔可以遲過劇集嘅、集數嘅唔可以遲過 arc 嘅（有就取最早嗰個）；範圍 key 要喺集數範圍入面、唔可以重疊
  • selector：LEAVING_SOON_DAYS = 30；isLeavingSoon(removedAt, today) = today < removedAt 而且相差 ≤ 30 日；isRemoved(removedAt, today) = today >= removedAt。一集嘅有效下架日 = 集數 / arc / 劇集三層最早嗰個
  • 下架後影響：唔產生 SeriesEpisode（清單、chips、書架、最近收聽、繼續收聽、自動播下一集全部唔見；唔再 request 音檔）；但 catalog 要保留集名 / 碟面畀收藏 tab 出灰色「已下架」行（可左滑移除）；進度 localStorage 唔刪，重新上架即刻返出；續聽嗰集下架咗就跳去下一集未下架嘅，冇就收埋條
  • JSON schema / 測試：schema.ts readArc 放寬 episodes + 加 episodeDates、劇集層 addedAt（daily 都有）、三層 removedAt，dramas.schema.json（如有）同步；arcTiles「N 個短篇」只數已上架嘅；續播 / 自動播下一集唔可以跳入未上架 / 已下架集數；加「快將下架 / 已下架」嘅固定時鐘測試；e2e 用固定時鐘（E2E_NOW 10/19）加一個將來 arc 測
