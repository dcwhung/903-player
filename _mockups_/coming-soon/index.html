④ 上咗架之後

  • 上架當日（香港時間 00:00 起）自動變返正常短篇：chip / 一覽表行 / 主頁格同其他短篇一樣，可以播
  • 跟現有 NewBadge：14 日內有「新」，主頁格左上角「新」（讀屏「有新短篇」），一覽表排入「新上架」組
  • 14 日之後「新」消失，排返「未聽完」/「已聽完」
  • 唔使任何人手改 drama.json（上架日就係「新」嘅起計日）

⑤ drama.json schema 建議（未改真 schema）

而家 ArcDefinition 已經有 optional addedAt（用嚟計 14 日「新」）。建議直接用佢做上架日，唔加新欄位： 

"arcs": [
  { "name": "我心不死", "disc": "arcs/heart/disc.webp", "episodes": 37 },
  {
    "name": "XXX",
    "addedAt": "2026-11-12",          // 將來日子 = 即將上架；當日起自動變正常 + 「新」
    "disc": "arcs/xxx/disc.webp",     // optional，冇就用劇集碟面（灰咗）
    "episodes": 20                    // 知道就寫；唔知可以唔寫（見下）
  }
]
  • 判斷：addedAt > hkToday() = 即將上架；selector 一個 isArcUpcoming(addedAt, today)，同 isArcNew 放埋一齊
  • 上架時間：上架 = 香港時間 addedAt 當日 00:00（用戶已確認），即係 hkToday() >= addedAt 就當已上架，唔使寫時間
  • 未上架嘅集數：唔產生 SeriesEpisode（唔砌音檔 URL、唔 probe、唔入進度 / 收藏 / mini player / 續聽），只出一個 UpcomingArc { arc, addedAt, count? , disc? } 畀 UI
  • episodes 可唔可以省略：建議 schema 容許「addedAt 係將來」嘅 arc 唔寫 episodes（顯示「集數待定」）；已上架嘅 arc 照舊必填，parse 時按 addedAt 同 build 日子驗唔到（日子會過），所以驗證只係「冇 episodes 就一定要有 addedAt」，到上架當日仲未補 episodes 就當未上架（log warning）
  • 逐集上架（P8 寫「短篇 / 集數」）：第一步淨係做 arc 層。如果要一個短篇逐集出，可以之後加 optional episodeDates: { "11": "2026-11-19" }（集數 → 日子，冇寫跟 arc 嘅 addedAt），未到期嘅集數喺清單顯示「11/19 上架」灰行
  • 整套新劇：劇集層 addedAt 係將來日子 → 呢期唔處理（主頁照唔顯示 / 或者 enabled: false），要嘅話另開 issue
  • JSON schema / 測試：schema.ts readArc 放寬 episodes、dramas.schema.json（如有）同步；arcTiles「N 個短篇」只數已上架嘅；e2e 用固定時鐘（E2E_NOW 10/19）加一個將來 arc 測
