用戶已決定：最近收聽 icon = 歷史；同步掣 = ⇅ +「同步」；同步面板 = 米白卡 + QR 做主角、標題置中；QR = M + 細 logo，最多最近 50 集 + 全部收藏；分享連結有齊；匯入確認 = 並排圖示；覆蓋要再確認；連結 24 小時過期；本機全新淨出「匯入」；匯入完跳去第三個 tab；淨係一粒分享 / 複製掣。

① 主頁第三個 tab：三種狀態

  • A 有收藏 → ★：收藏 box + 最近收聽
  • B 冇收藏、有收聽記錄 → 歷史 icon：成個 tab 係最近收聽（見 ②）
  • C 兩樣都冇 → tab 唔出
  • 收藏由有變冇：膠囊留喺第三格，★ 縮細轉走、歷史 icon 轉入嚟（520ms / 260ms）；減少動態 = 直接換

② 冇收藏版收藏 tab = 最近收聽 + 同步掣

  • 最近收聽最多 10 集，佔滿 tab 區、自己捲；手機一欄，橫版兩欄
  • 每行：碟 | 名（左對齊，太長用 … 收尾）| 固定闊度 ☆ 欄，☆ 全部垂直對齊
  • 同步掣（框住嗰粒）喺最近收聽標題右邊，有收藏 / 冇收藏都係；冇收聽記錄 = 冇同步掣

③「同步至另一部機」面板（定稿：米白卡 + QR 做主角）

  • 手機：浮起米白卡，QR 置中放大（300 px），字同掣喺下面
  • 窄橫版 / 闊橫版：QR 喺左邊用盡卡高；右欄標題貼頂、掣同私隱字貼底，中間內容平均分佈
  • QR：M + 細 logo；最多放最近 50 集 + 全部收藏；計數顯示用戶完整數字
  • 淨係一粒掣：支援 Web Share →「分享連結」；唔支援 →「複製連結」
  • 標題文字置中（icon 左、✕ 右）；橫版標題喺右欄入面置中（卡高唔夠放喺 QR 上面）
  • v5：次要掣「由另一部機匯入」→「掃描 QR code」（主）/「貼上連結」（次）→ 同一個匯入確認（最後一個舞台）；iPhone 主畫面 app 用 app 自己嘅相機掃

④ B 機開連結 → 匯入確認（定稿：並排圖示）

  • 標題置中（同 ③ 一致）；連結 → 本機兩個 icon + 箭咀，下面即場寫「合併後」幾多
  • 掣列：「取消」靠左（文字掣）；「覆蓋」+「合併」一組靠右，手機窄位都係左右分組
  • 撳「覆蓋」先出確認：掣列原位換成紅字「覆蓋會清走本機嘅 …」+「返回」/「確認覆蓋」；平時冇紅字
  • v5 合併：每集 updatedAt 較新嗰邊成條勝（位置 + 聽完一齊跟）；收藏比「加入」同「刪除」時間，較新動作勝。覆蓋：清走本機嘅，換成連結入面嘅
  • v5：匯入完 Toast 有「復原」（6 秒；匯入前快照留 24 小時）
  • 撳完都會用 history.replaceState 清走 #import=（睇假網址列）；匯入完跳去第三個 tab
  • 喺 Safari 開咗：iOS 主畫面 app 同 Safari 儲存分開，頂部提示教用戶返 app 入面再掃；照匯入就入咗 Safari（Q2）

⑥ v5 完整流程：A 機 → B 機（四種組合）

  • 揀組合 + 路線，再一步步睇（撳步驟、「下一步」，或者直接撳畫面入面框住嘅掣）； 藍框 = 呢一步要郁嘅機
  • 匯入入口（Q1 / Q2）：B 機喺 app 入面「由另一部機匯入」→「掃描 QR code」（主）/「貼上連結」（次）；iPhone 主畫面 app 用自己相機掃，記錄先會入 app
  • 全新 B 機嘅入口（要你揀）：v4 定咗「冇記錄 = 第三格唔出」，咁全新部機冇路去匯入。 E1：未有記錄時第三格出 ⇅，撳即彈「由另一部機匯入」卡； E2：第三格係一頁「未有收聽記錄」空白頁，入面直接有兩粒掣。有記錄之後第三格照 v4 變 ★ / 歷史
  • 匯入確認跟 Q4–Q11：較新者成條勝、收藏比加入 / 刪除時間、截短 QR 覆蓋要寫明、Toast「復原」

    ⑦ v5 例外情況

    • 相機權限被拒 / 電腦冇相機：退返「貼上連結」
    • 掃到其他 QR：唔跳走，紅字提示，繼續掃
    • 連結格式太新（Q9）：自動 registration.update()；有新版就 reload 再讀（#import= 留住），冇先話「連結唔啱用」
    • QR 截短 + 覆蓋（Q7）、匯入完「復原」（Q8）；連結壞 / 過期見 ④「連結唔啱用」

    ⑤ 實作建議（純文字）

    壓縮格式（v1，v5 改用 episode ID）

    1. 原樣 episode ID（Q3）：Phase −1（v1.29.0）之後進度 / 收藏 key = show:<showId>:<YYYY-MM-DD>、 drama:<dramaId>:<arcId>:<no>、 drama:<dramaId>:<YYYY-MM-DD>；唔使 catalog 對照，靠 deflate 壓重複前綴。v4 嘅短 ref 作廢
    2. {"v":1,"t":匯出分鐘,"p":[[id,幾耐前(分),長度(秒),位置(秒；-1 = 聽完)]…],"b":[[id,幾耐前加入]…],"x":[[id,幾耐前刪除]…],"n":{"p":總集數,"trunc":QR 截短咗}}（x = 30 日內嘅收藏 tombstone）
    3. TextEncoder → CompressionStream('deflate-raw') → base64url；Safari 16.4+ / Chrome 103+ / Firefox 113+，冇就唔出同步掣
    4. 連結 https://…/903-player/#import=1.<base64url>：版本號放喺壓縮外面；舊版見到 2. 先檢查更新（Q9，見 ⑦）
    5. 過期：t 超過 24 小時當過期
    6. 任何一步（base64 / 解壓 / JSON / schema）失敗都係「連結唔啱用」，唔寫 storage
