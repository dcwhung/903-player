QR 同步進度（P9 #11）+ 冇收藏版收藏 tab（P7 改動）

底圖係 v1.27.0（feature/bookmark/episode）真截圖：手機直版 390×844、窄橫版 844×390、闊橫版 1300×800（當 laptop）。tab、最近收聽、面板、Toast 係疊上去嘅 HTML，舞台入面嘅掣撳得。

用戶已決定：最近收聽 icon = 歷史；同步掣 = ⇅ +「同步」；同步面板 = 米白卡 + QR 做主角、標題置中；QR = M + 細 logo，最多最近 50 集 + 全部收藏；分享連結有齊；匯入確認 = 並排圖示；覆蓋要再確認；連結 24 小時過期；本機全新淨出「匯入」；匯入完跳去第三個 tab；淨係一粒分享 / 複製掣。

① 主頁第三個 tab：三種狀態

  • A 有收藏 → ★：收藏 box + 最近收聽
  • B 冇收藏、有收聽記錄 → 歷史 icon：成個 tab 係最近收聽（見 ②）
  • C 兩樣都冇 → tab 唔出
  • 收藏由有變冇：膠囊留喺第三格，★ 縮細轉走、歷史 icon 轉入嚟（520ms / 260ms）；減少動態 = 直接換

② 冇收藏版收藏 tab = 最近收聽 + 同步掣

  • 最近收聽最多 10 集，佔滿 tab 區、自己捲；手機一欄，橫版兩欄
  • 每行：碟 | 名（左對齊，太長用 … 收尾）| 固定闊度 ☆ 欄，☆ 全部垂直對齊
  • 同步掣（框住嗰粒）喺最近收聽標題右邊，有收藏 / 冇收藏都係；冇收聽記錄 = 冇同步掣

③「同步至另一部機」面板（定稿：米白卡 + QR 做主角）

  • 手機：浮起米白卡，QR 置中放大（300 px），字同掣喺下面
  • 窄橫版 / 闊橫版：QR 喺左邊用盡卡高；右欄標題貼頂、掣同私隱字貼底，中間內容平均分佈
  • QR：M + 細 logo；最多放最近 50 集 + 全部收藏；計數顯示用戶完整數字
  • 淨係一粒掣：支援 Web Share →「分享連結」；唔支援 →「複製連結」
  • 標題文字置中（icon 左、✕ 右）；橫版標題喺右欄入面置中（卡高唔夠放喺 QR 上面）
  • （建議）次要掣「由另一部機匯入」→ 貼上連結 → 同一個匯入確認（最後一個舞台）；解決 iOS 主畫面 app 掃唔到 QR 嘅問題（見 ⑤）

④ B 機開連結 → 匯入確認（定稿：並排圖示）

  • 標題置中（同 ③ 一致）；連結 → 本機兩個 icon + 箭咀，下面即場寫「合併後」幾多
  • 掣列：「取消」靠左（文字掣）；「覆蓋」+「合併」一組靠右，手機窄位都係左右分組
  • 撳「覆蓋」先出確認：掣列原位換成紅字「覆蓋會清走本機嘅 …」+「返回」/「確認覆蓋」；平時冇紅字
  • 合併：每集取較新（updatedAt）嘅位置；任何一邊聽完當聽完；收藏兩邊加埋。覆蓋：清走本機嘅，換成連結入面嘅
  • 撳完都會用 history.replaceState 清走 #import=（睇假網址列）；匯入完跳去第三個 tab
  • （建議）喺 Safari 開咗：iOS 主畫面 app 同 Safari 儲存分開，所以頂部加提示教用戶喺 app 入面貼上（見 ⑤）

⑤ 實作建議（純文字）

壓縮格式（v1）

  1. 只放 id，唔放 URL：進度 key 而家係音檔 URL（約 120–200 字），匯出時轉短 ref，匯入時用 catalog 砌返 URL：
    • 節目：s<節目>.<日數>（2020-01-01 起計；開咪時間唔同 fileTime 先加 .HHMM）
    • 短篇劇：r<劇>.<短篇 index>.<集數>
    • 每日劇：y<劇>.<日數>（重播加 .r）
  2. 節目 / 劇 id 放 payload 字典（s / d），唔靠 catalog 次序；短篇 index 要 drama.json arcs 只加喺尾（或者用短篇名，每集多 6–9 byte）
  3. {"v":1,"t":匯出分鐘,"s":[…],"d":[…],"p":[[ref,幾耐前(分),長度(秒),位置(秒；-1 = 聽完)]…],"b":[[ref,幾耐前]…]}
  4. TextEncoder → CompressionStream('deflate-raw') → base64url；Safari 16.4+ / Chrome 103+ / Firefox 113+，冇就唔出同步掣
  5. 連結 https://…/903-player/#import=1.<base64url>：版本號放喺壓縮外面；舊版見到 2. 就話「連結唔啱用」
  6. 過期：t 超過 24 小時當過期
  7. 任何一步（base64 / 解壓 / JSON / schema）失敗都係「連結唔啱用」，唔寫 storage
