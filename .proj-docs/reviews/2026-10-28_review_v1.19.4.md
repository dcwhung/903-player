#### S-536 — 「喺 groups 搵短篇嘅續聽集」寫咗兩次

- 位置：`src/pages/useDramaPage.ts` `useArcPick`（`groups.flatMap((g) => g.items).find((s) => s.arc === arc)?.resume`）同新 `pickedArcResume`（同一句）
- 描述：兩個地方都要「某個短篇嘅 `resume`」，lookup 一字不差抄咗。將來如果 `resume` 規則（例如改用 `resumeAt`）或者 groups 結構改，要記住改兩處
- 方案 A：抽 module-level helper `arcResume(groups, arc)`，`useArcPick` 同 `pickedArcResume` 都用佢。代價：多一個 3 行 function
- 方案 B：`useArcOrder` 順手 return 一個 `resumeOf(arc)`（`useMemo` 一個 `Map<arc, resume>`），兩邊都用。代價：多一個 return field，`useArcPick` 簽名要改
- 推薦：**A**，改動最細，唔郁 hook 簽名

#### S-537 — 「揀返預設短篇」guard 喺可到達狀態冇分別；測試名「left off」同狀態唔夾

- 位置：`src/pages/useDramaPage.ts` `pickedArcResume` 嘅 `arc === current?.arc`；`src/pages/DramaPage.test.tsx` “starts where the drama left off when no 短篇 was picked”
- 描述：
    1. 「未載入 + 播緊其他嘢」只會喺第一次入出現：有進度就唔係第一次入，`useAutoplayDrama` 一入頁就 `startDrama`，即刻載入呢套劇。所以 `start` 存在時呢套劇一定冇進度，`pickSeriesStart` = 成套劇第一集 = 第一個短篇嘅 `resume`。guard 拎走結果一樣（mutation 改 `false`，33/33 pass）。guard 本身啱（表達咗「冇揀先照舊」嘅語意，將來改自動播規則都穩陣），只係而家冇測試能夠分辨。
    2. 測試名講「where the drama left off」，但測試狀態冇任何進度，實際斷言係「成套劇第一集」
- 方案 A：喺 `pickedArcResume` 加一句註解講明「而家未載入就一定冇進度，guard 係防將來改自動播規則」；測試改名做 “starts the drama's first episode when no 短篇 was picked”。代價：註解 + 改名
- 方案 B：拎走 guard，`useStandby` 一律用睇緊嘅短篇嘅 `resume`（冇揀就係預設短篇嘅 `resume`），少一個分支。代價：將來如果「有進度都唔自動播」，冇揀時會播預設短篇嘅第一個未聽完集，而唔係 `pickSeriesStart` 嘅「上次聽到嗰集」，同用戶規則 3 唔一致
- 推薦：**A**，保留 guard 守規則 3，註解交代點解而家測唔到

// src/pages/useDramaPage.ts

/** 某個短篇嘅續聽集（全集表 ▶ 同揀短篇載入都播呢集） */
const arcResume = (
    groups: readonly { items: readonly ArcSummary[] }[],
    arc: string | undefined,
): SeriesEpisode | undefined => groups.flatMap((g) => g.items).find((s) => s.arc === arc)?.resume;

// useArcPick 入面
const resume = arcResume(groups, arc);
if (resume) void player.load(resume);

/**
 * 揀咗嘅短篇（同預設嗰集唔同短篇先算）嘅續聽集；冇揀就 undefined。
 * S-537：而家未載入一定係第一次入（冇進度），預設嗰集同第一個短篇嘅續聽集一樣；
 * 呢個 guard 係防將來改自動播規則，冇揀時都要照舊用 pickSeriesStart（上次聽到嗰集）
 */
const pickedArcResume = (
    groups: readonly { items: readonly ArcSummary[] }[],
    arc: string | undefined,
    current: SeriesEpisode | undefined,
): SeriesEpisode | undefined => (arc === current?.arc ? undefined : arcResume(groups, arc));
