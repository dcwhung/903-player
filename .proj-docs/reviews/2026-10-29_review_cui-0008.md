### c18 round-trip 覆核（`0a66fea`）— developer 嘅「等同」講法

Developer 講：series case 由比完整網址改做比相對錄音路徑係等同，因為另一個 test 驗 R2 base 一樣。逐點驗：

1. **相對路徑 ⇔ 網址（同一個 host 前提下）：成立。** 兩邊網址都係 app 嘅 `buildEpisodes` 砌：`<audioBase(host)><encodePath(segments)>`，`encodePath` = 每段 `encodeURIComponent` 再用 `/` 接。`decodedPath` 逐段 `decodeURIComponent` 係佢嘅逆運算；segment 由 folder 樹嚟，入面唔會有 `/`，所以「解碼後相對路徑一樣」⇔「encode 後一樣」。NFC / NFD 差異 decode 後保留（`decodeURIComponent` 唔 normalise），照樣捉到。
2. **「另一個 test 驗 shared R2 base」唔係理由。** `script packaging > should use the same R2 base as the app` 比嘅係 script 嘅 `DRAMA_AUDIO_BASE` 同 app 嘅；但舊 round-trip 兩邊都係經 app 嘅 `buildEpisodes`，從來冇用過 script 嘅 base。所以呢個 test 同 round-trip 改法無關。
3. **真正少咗嘅係 host。** 舊 test 網址包住 base，base 跟 `audio.host` 揀，所以生成出嚟 host 唔係 `r2` 舊 test 會紅；新 `audioPathOf` 每邊用自己嘅 host 揀 base，host 唔同都會過。**Mutation 實證**（scratchpad 副本，將 `scripts/dramaFromFolder.mjs:465` 改做 `host: 'app'`）：6 個「should rebuild the same audio paths … from scratch」**全部照過**；但其他 6 個 test 紅（`new series drama` 3 個 `toMatchObject({ audio: { host: 'r2' } })` / app 驗收、`daily drama` 1 個、`--existing` titles 1 個、`verifyUrls` CLI end-to-end 1 個）。
4. 另外 `decodedPath` 用 `slice(base.length)` 冇驗網址真係以 base 開頭（同舊 `pathOfUrl` 一樣，唔係新問題，但而家多咗一個 base）。

**結論：** 成個 test 檔嘅保護冇變弱（host 回歸會被其他 6 個 test 捉到），c18 由「只 touch m4a + 比 json」升級做同 series 一樣嘅 `--existing` 不變（仲多咗 `errorsOf(issues) == []`）+ from-scratch 路徑對比，係淨增強。round-trip 本身就唔再自我完整 → S-570（🟢）。舊 daily describe 嗰個 c18 case 併入 `COMMITTED_IDS` 後斷言（`json` 等於 commit 版）冇少，「rerun flags kept」照樣覆蓋。

```js
// scripts/dramaFromFolder.mjs — S-571 方案 A + S-572 方案 A
/** 一個要寫嘅檔：上層 folder 要存在、寫得入，本身唔可以係 folder；錯就回傳點改，啱就 undefined */
const destinationProblem = (label, path, exampleName) => {
    const parent = dirname(path);
    if (!isDirectory(parent))
        return `[錯誤] ${label} 嘅 folder 唔存在：${parent}\n請先開好個 folder，或者檢查路徑有冇打錯（有空格要用引號包住）。`;
    if (isDirectory(path))
        return `[錯誤] ${label} 係一個 folder：${path}\n要畀檔案路徑，例如 ${join(path, exampleName)}`;
    try {
        accessSync(parent, constants.W_OK); // POSIX 權限 / 唯讀 mount；Windows ACL 唔保證
    } catch {
        return `[錯誤] ${label} 嘅 folder 冇權限寫入：${parent}\n請揀另一個 folder。`;
    }
    return undefined;
};

const checkDestinations = (args) => {
    const targets = [['輸出檔（--out）', outputPath(args), 'drama.json']];
    if (args.report !== undefined) targets.push(['--report', resolve(args.report), 'report.txt']);
    const problem = targets.map((t) => destinationProblem(...t)).find(Boolean);
    if (problem !== undefined) throw new Error(problem);
};
```
