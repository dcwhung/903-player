### 🟡 Warning

#### W-470 — `gaugeArt()` 只用嚟斷言 `null`，selector 失效會變空測試；規則 3 冇測試

- 位置：`src/pages/DramaPage.test.tsx` 第 65 行 `gaugeArt`；第 213 行、第 340 行兩個 `expect(gaugeArt()).toBeNull()`；“marks no 短篇 chip as 播緊 while another 短篇 is browsed”（第 366 行）
- 描述：
    1. `gaugeArt` 靠 `PlayerPanel.module.css` 嘅 `.discArea` class 名。兩個用法都係「搵唔到」=「啱」，所以 class 改名、`Disc` 唔再用 `<img>`、或者測試 CSS module 策略改做 scoped，兩個測試都會照綠（mutation 改 selector 做 `.discAreaX img`，31/31 pass 證實）。
    2. 用戶確認嘅規則 3（播緊其他嘢時揀短篇唔載入，碟面維持黑碟）冇任何斷言；而家靠 `useArcPick` 見 `isPlaying` 就 return 保證，將來有人改「播緊都載入」或者改 `art` 條件做「有揀短篇就出封面」都唔會有測試 fail
- 影響：唔影響而家行為；係防回歸能力不足。用戶專登講清楚咗規則 3，冇測試守住
- 方案 A：喺同一個 test file 加正向錨點：喺 “loads the picked 短篇 paused after a row is picked” 加 `expect(gaugeArt()?.getAttribute('src')).toBe(dramaArtFor(youth!))`（揀完載入就有圖），咁 selector 失效呢個測試會 fail；另外喺 “marks no 短篇 chip as 播緊…” 撳 chip 之後加 `expect(gaugeArt()).toBeNull()` 同 `expect(audio.src).toBe(OTHER_REC.url)` 守規則 3。代價：多兩三行
- 方案 B：喺 `gaugeArt` 入面先 `getByRole('main').querySelector('.discArea')` 再斷言個 container 存在（`expect(area).not.toBeNull()`），然後先揀 `img`；selector 失效會即刻 throw。規則 3 同方案 A 一樣加斷言。代價：helper 入面有 `expect`，風格上少見
- 推薦：**A**。正向斷言同時證明 selector 揀中碟面，又同用戶規則 2 一一對應；規則 3 加斷言係必須
