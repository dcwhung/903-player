2. **撳把手入播放頁**：mini player 路徑直接用 `miniPlayer.onOpen`（節目帶 `{ url }`，同 mini player / ↗ 一樣）；`zoomInto(zoomKey.homeHandle, go)`。減少動態：`zoomInto` → `canViewTransition()` 喺撳嗰刻先叫 `prefersReducedMotion()`，冇 cache，符合 CLAUDE.md 動態規則；e2e 減少動態驗 `runs.length === 0` 而且有轉頁
3. **✕ 閂咗嘅卡**：`restoreMiniPlayer` + `openHomePlayerCard` 再 `navigate`。`dismissWith` 用 `player.stop()`（pause，唔 unload），`recording` 仍然載入，restore 後 `useAudioBusy` = true → `useAutoplayShow` 唔會 `startShow`；unit 驗 `data-busy="true"` + `audio.paused`
4. **過場命名**：用 `'zoom'` kind，`[data-zoom-source]` 得 `zoom-tile` 名；`[data-home-handle]` 只喺 `close` / `zoom-handle` / `unzoom-handle` 先攞 `player-panel`，唔會撞名

6. **死碼**：`homeReturn.ts`、`HomeAwayObserver`、`cardFolded`、`onUnfold`、`HomePageFoldOnReturn.test.tsx`、W-788 半闊分支都清走；`createFlagStore` / `useOnPlayStart` 仍有其他用家。`homeCard.reopenPlaying` **唔係**死 key：HomeView 播緊時把手照用（`HomePlayerHandle` `REOPEN_LABEL.playing`），註解已更新
