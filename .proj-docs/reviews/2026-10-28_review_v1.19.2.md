### 🟡 Warning

#### W-469 — mini player 路徑仲有「最近一日 fallback」殘留：誤導註解、行唔到嘅 branch、過時測試名

- 位置：
    - `src/selectors/miniPlayer.ts` `miniPlayerTags` 註解第 35–36 行（今次 commit 改過嘅一句）：「其他日子（例如今日節目頁用嘅最近一日）唔係今日，所以冇標籤」
    - 同一個 function：`return r.date === today ? 'today' : undefined;`
    - `src/selectors/miniPlayer.test.ts`：“puts an older episode before the latest-day fallback too”、“leaves the latest-day fallback untagged, as it is not today”
    - `src/components/MiniPlayer/MiniPlayer.test.tsx`：“should leave untagged dots plain (latest-day fallback)”、“should show no tag without tags (latest-day fallback, drama)”
- 描述：`miniPlayerTags` 只有 `useMiniPlayer` 用，今日節目頁根本冇用佢，所以註解講「今日節目頁用嘅最近一日」係錯嘅。而家 mini player 清單 = `[重溫?] + showsOnDate(today)`，除咗排第一嗰個重溫，其餘一定係今日，所以 `undefined` 嗰條 branch 喺 production 行唔到。測試名仲描述一個已經唔存在嘅情況。用戶今次特別要求清走 mini player 路徑嘅 fallback 殘留
- 影響：唔影響行為。不過下一個人睇到註解同測試名，會以為 mini player 仲有 fallback，甚至「修返」佢；用戶已經兩次改呢度嘅規則，誤導註解嘅代價比平時高
- 方案 A：簡化 `miniPlayerTags`：清單除咗重溫一定係今日，改做 `hasRewatch && i === 0 ? 'rewatch' : 'today'`，拎走 `today` 參數。刪 / 改兩個 selector fallback 測試做「今日冇節目只得重溫」。`MiniPlayer.test.tsx` 兩個測試名改做講「冇 tags（例如廣播劇）」。代價：如果將來 mini player 再加非今日項目，要記得加返判斷
- 方案 B：保留 `r.date === today` 做防守，只改註解做「清單除咗重溫都係今日（見 useListedRecordings）；呢個判斷只係防守」，同時改晒上面四個測試名
- 推薦：**B**。改動最細，冇行為風險，又唔會令 selector 依賴 caller 嘅不變量；註解同測試名要同今次規則一致

## 修訂後代碼（W-469 方案 B 示意，未套用）

```ts
// src/selectors/miniPlayer.ts

/** 節目名旁邊嘅細標籤：rewatch = 載入緊、唔喺今日清單嘅節目錄音（「重溫」，揀定自動播都係），today = 今日節目（「今日」） */
export type MiniPlayerTag = 'rewatch' | 'today';

/**
 * 每段錄音嘅標籤：排最前嘅舊集係「重溫」，日子係今日就「今日」。
 * mini player 清單除咗重溫都係今日（見 useListedRecordings，唔再用最近一日），
 * 日子判斷只係防守
 */
export const miniPlayerTags = (
    list: Recording[],
    hasRewatch: boolean,
    today: string,
): (MiniPlayerTag | undefined)[] =>
    list.map((r, i) => {
        if (hasRewatch && i === 0) return 'rewatch';
        return r.date === today ? 'today' : undefined;
    });
```
