#### S-505 — 有重溫但今日未有節目（用緊 fallback 日子）時，region 名仍然講「今日節目」

- 位置：`src/hooks/useMiniPlayer.ts` 嘅 `listLabels`；`zh-HK.ts` 嘅 `miniPlayer.regionRewatch`
- 描述：例如星期日播緊舊集，清單係「重溫 + 最近一日（例如星期五）嘅節目」。讀屏會讀「正在播放（重溫及今日節目）」，但其實清單入面冇今日節目。之前冇重溫時，`miniPlayer.region` 都有同樣問題（v1.11.0 已經存在）。
- 方案 A：用 `tags.includes('today')` 決定用 `regionRewatch` 定新嘅 `regionRewatchOnly`（「正在播放（重溫及最近節目）」）
- 方案 B：region 名統一做「正在播放」，第幾個 / 重溫交俾指示點同開頁掣講
- 推薦：B（簡單，亦唔會再錯）

#### S-506 — 啟動時如果 recordings 遲過 player 還原，今日節目會短暫被標做「重溫」

- 位置：`src/hooks/useMiniPlayer.ts` 嘅 `useListedRecordings` → `rewatchUrl`
- 描述：如果 player 喺 recordings 載入之前已經有 recording（例如以後加「重開 app 續播」，或者 recordings 刷新時清單暫時係空），咁 `listed = []`，播緊嘅今日節目會被 `miniPlayerRecordings` 排最前，同時 `rewatchUrl` 有值，於是會短暫顯示藍色「重溫」標籤，region 名都會講重溫。等 recordings 載入完，佢入咗 `listed`，`rewatchUrl` 變返 `undefined`，就會自動修正，`chosen` 亦會重設。
- 影響：而家主頁係 app 嘅起點，player 開頭冇嘢，所以未見過觸發條件；唔會播錯嘢，只係閃一下標籤。
- 方案 A：`status === 'loading'` 時唔標 rewatch（`rewatchUrl` 用 `undefined`），清單照樣顯示
- 方案 B：保持現狀，加一個測試記低呢個預期（自動修正）
- 推薦：A，一行，加一個測試

#### S-507 — 有重溫時掃去今日同一個節目再撳開頁，會開到舊集

- 位置：`src/hooks/useMiniPlayer.ts` 嘅 `onOpen`；`src/pages/useShowPage.ts` 嘅 `useShowEpisodes`
- 描述：例如重溫係公子會 10/10，用戶掃去今日嘅公子會（未載入），撳碟 / 名開節目頁。去到節目頁，`playing`（載入緊嘅舊集，同一個 showId）會蓋過 `pickInitialRecording`，所以節目頁顯示嘅係 10/10 嘅舊集，唔係 mini player 上面睇緊嗰集。換做唔同節目就冇呢個問題（會 autoplay 今日嗰集）。
- 影響：同一個節目「重溫 + 今日」係呢個功能最常見嘅組合；用戶要喺節目頁再揀一次日子。
- 方案 A：未載入嗰項開頁時帶埋日子（例如 `/show/:id?date=…`，或者 navigation state），節目頁揀嗰日但唔 autoplay，保持「掃唔會播」嘅原則
- 方案 B：保持現狀，喺 T9 設計備註寫明開頁一定跟 player
- 推薦：先問用戶想要邊個；A 嘅改動比較大

#### S-508 — `MiniPlayer` 嘅 JSDoc 被新常數隔開咗

- 位置：`src/components/MiniPlayer/MiniPlayer.tsx`，大約 45–52 行
- 描述：原本描述 `MiniPlayer` 嘅註解（「用 portal 掛喺 body…」）而家喺 `DOT_VARIANTS` 上面，`DOT_VARIANTS` 嘅註解反而貼住佢自己，令 IDE 嘅 hover 文檔錯晒位。
- 方案 A：將 `DOT_VARIANTS` / `dotVariant` 搬去 JSDoc 上面
- 方案 B：抽去 `miniPlayerDots.ts`
- 推薦：A

## 修訂後代碼（S-506 方案 A 片段）

```ts
const useListedRecordings = (loaded: Track | null) => {
    const { recordings, status } = useRecordings();
    const today = hkToday();
    const listed = useMemo(() => todayRecordings(recordings, today), [recordings, today]);
    const list = useMemo(() => miniPlayerRecordings(listed, loaded), [listed, loaded]);
    // S-506：清單未載入完就分唔到係咪今日，唔好先標重溫
    const rewatchUrl =
        status !== 'loading' && list.length > listed.length ? list[0]?.url : undefined;
    return { today, list, rewatchUrl };
};
```
