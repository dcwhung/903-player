### 🟡 Warning

#### W-468 — 主頁節目格自動播嘅舊集會繼承之前嘅 showPick，返主頁變咗「重溫」

- 位置：`src/hooks/useStartPlayback.ts` `startShow`（主頁 `HomePage.tsx:48-50` 節目格 onClick 會用）；`src/pages/useShowPage.ts` `useAutoplayShow`（只喺 `playingUrl === undefined` 或者有 `requested` 時先 `clearShowPick`）
- 描述：showPick 用 showId 做 key，只會喺節目頁自動播時清走。不過主頁節目格係**喺主頁 click handler 入面先 `startShow` 再 navigate**。去到節目頁時 `playingUrl` 已經有值，`useAutoplayShow` 唔會入任何分支，所以唔會清 pick。`pickInitialRecording` 揀嘅係 `findLast(date <= today)`，如果呢個節目今日唔播，或者今日嗰集未上架，揀中嘅就係舊集。
- 重現步驟（2026-10-19 星期一，公子會今日冇播；用臨時 RTL 測試重現，跑完已經刪咗）：
    1. 節目頁公子會揀 10/10（`picked = gongzi`）
    2. 返主頁，10/10 顯示做重溫 ✓
    3. 撳主頁「公子會」格，自動播 10/17
    4. 返主頁：預期 `正在播放（今日節目）`，並且停咗 10/17；實際係 `正在播放（重溫及今日節目）`，10/17 繼續播，仲標咗重溫
- 影響：違反用戶決定 1（自動播嘅舊集唔算重溫）。只要同一個 session 入面揀過一次舊集，之後由主頁格入同一個節目就會中。每星期播一次嘅節目大部分日子都會揀到舊集，所以觸發機會唔細
- 方案 A：喺 `useStartPlayback.startShow` load 之前 `clearShowPick()`。任何程式自動揀嘅集都唔算用戶揀，一處就搞掂；`useAutoplayShow` 嗰個分支嘅 `clearShowPick` 就變成多餘，可以刪。代價：`hooks/useStartPlayback` 要 import `hooks/showPick`（同一層，冇問題）
- 方案 B：喺 `HomePage` 節目格嘅 onClick 先 `clearShowPick()` 再 `startShow`。改動範圍最細，但規則散咗喺兩處，以後再有新嘅自動播入口好容易漏
- 推薦：**A**，並且加一個 HomePage 回歸測試（步驟同上）

### 🟢 Suggestion

#### S-530 — `showPick.ts` 註解講「自動接集都仲算用戶揀」，但節目根本唔會自動接集

- 位置：`src/hooks/showPick.ts` 第 4–7 行
- 描述：`nextTrack` 只會接短篇廣播劇，903 節目播完就停。所以「記節目唔記集數」嘅理由喺現行規則下唔成立，讀者會以為節目有自動接集。設計仍然係 showId（用戶要求），只係註解誤導
- 方案 A：改做「記節目唔記集數：同一個節目喺節目頁再揀第二集都仲算重溫；節目唔會自動接集（見 `player/nextTrack.ts`）」
- 方案 B：刪走嗰句
- 推薦：A

#### S-531 — 帶入嚟嘅 url 搵唔到集數時，history state 唔會清走

- 位置：`src/pages/useShowPage.ts` `useRequestedEpisode` / `useAutoplayShow`
- 描述：只有 `requested` 搵到先會 `consume()`。如果 state 嘅 url 唔喺 `episodes`（例如 recordings 刷新咗、嗰集冇咗），state 會一直留喺 history entry。之後如果 recordings 再刷新，嗰集又出返嚟，`requested` 會突然有值，effect 就會喺用戶唔知情下 load 嗰集，打斷播緊嘅嘢
- 影響：要 recordings 喺停留節目頁期間變動先會中，機會好低
- 方案 A：`status === 'ready'` 時只要 state 有 url 就 consume，唔理搵唔搵到
- 方案 B：用 `useRef` 記低「呢次入頁已經處理過 state」
- 推薦：A，一行改動

#### S-532 — 冇測試鎖住「用完即清 history state」

- 位置：`src/pages/HomePage.test.tsx` S-507 兩個測試；`src/pages/ShowPage.test.tsx`
- 描述：S-507 測試只驗證去到節目頁會播啱嗰集，冇驗證 `location.state` 已經清咗，亦冇驗證返上一頁再入唔會再觸發。日後有人刪走 `consume()`，測試仍然會綠
- 方案 A：喺 ShowPage 測試用 `initialEntries: [{ pathname, state: { url } }]`，斷言之後 `location.state` 係 `null`，以及手動 `load` 第二集之後唔會被拉返去 requested 嗰集
- 方案 B：喺 HomePage 測試 navigate(-1) 再 navigate(1) 驗證
- 推薦：A
