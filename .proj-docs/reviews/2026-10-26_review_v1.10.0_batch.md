#### 🟡 W-460 — 呢套劇已經載入（未有進度）都會被當成第一次入

- 位置：`src/hooks/useStartDrama.ts` `isFirstSeriesVisit`；`src/pages/HomePage.tsx:97`；`src/pages/useDramaPage.ts:111-114`
- 描述：判斷第一次入只睇 localStorage 進度，冇睇 player 載入緊乜。以下流程係行得到嘅：
    1. 第一次入 → 喺全集表撳一行（`sheet.pick` → `useArcPick`）。冇嘢播緊，所以會 `player.load(resume)`，**唔 autoplay**

    3. 返主頁，mini player 顯示呢套劇（暫停，`dramaMiniPlayer`）
    4. 撳返呢套劇個格 → `isFirstSeriesVisit` 係 true → 跳過 `startDrama`，即係唔行 W-456 嗰條「已載入就續播」路線。入頁時 `useFirstVisitOnEntry` 都係 true → **全集表又彈出嚟**，但明明呢套劇已經載入咗。由 mini player 入頁都一樣
- 影響：UX regression，W-456 嘅行為喺呢個 edge case 失效；用戶會覺得 app 唔記得自己揀過嘅短篇
- 方案 A（推薦）：`isFirstSeriesVisit` 多收一個 `recording`，`isEpisodeOfDrama(recording, drama.id)` 成立就唔當第一次入。HomePage 同 `useFirstVisitOnEntry` 都傳 `player.recording` 入去
    - Trade-off：多一個參數；判斷集中喺一個地方，兩邊行為一致
- 方案 B：`useArcPick` 冇播放時都 `persist` 一個 0 秒進度
    - Trade-off：會令 `hasNoProgress` / 書架「收聽中」都當咗佢聽過（T5 次序都會郁），副作用大
- 測試：DramaPage「揀咗一行就返主頁再撳格 → 唔開全集、會續播已載入嗰集」；HomePage「載入咗未有進度嘅劇，撳格會 play()」

#### 🟡 W-458 — 讀 canvas 嘅錯誤冇處理

- 位置：`src/components/HomeLandscapeGrid/bannerEdges.ts:86-121`
- 描述：`readBannerEdges` 喺 `img.onload` 入面直接 call。`getContext` 返 null（jsdom、iOS canvas 記憶體用盡）同 `onerror` 都有處理，**但係 `drawImage` / `getImageData` 一 throw 就冇人接**。例如將來橫額改由 CDN / 其他 origin serve 而冇 CORS，canvas 被 taint 會 `SecurityError`；又或者 decode 失敗。結果係：
    1. `resolve` 永遠唔會被 call，cache 入面嗰個 promise 永遠 pending
    2. Exception 變成 uncaught error，會去到 `window.onerror`
- 畫面上會 fallback 做 `--color-surface` 底色（尚算 graceful），但呢個係 checklist 嘅「缺少錯誤處理」
- 影響：而家 bundle 圖同源，機會低；不過呢個 failure mode 靜靜雞，亦冇測試
- 方案 A（推薦）：喺 `readBannerEdges` 入面 `try { … } catch { return null; }`
    - Trade-off：最細改動，所有 caller 都受保護
- 方案 B：喺 `loadBannerEdges` 嘅 onload 入面包 try/catch，再 `resolve(null)`
    - Trade-off：`readBannerEdges` 單獨 call 時仍然會 throw

#### 🟡 W-459 — 讀邊色同兩個 hook 冇測試

- 位置：`bannerEdges.ts` 第 83、87-96 行（`readBannerEdges` / `bandColors`）；`useBannerEdges.ts` 第 10、26-30 行
- 描述：只測咗純函數 `segmentAverages` / `edgeGradient`。以下嘢都冇 test：
    - canvas 讀取：`getContext` 返 null、band 嘅座標（右邊 `w - SIDE_PX`、下面 `h - TOP_BOTTOM_ROWS`）
    - `loadBannerEdges`：cache 同 onerror
    - `useBannerEdges`：換 src 時唔用舊圖嘅邊色
    - `useAspectRatio`：ResizeObserver
- 呢兩個 file 嘅 line coverage 係 79.6% / 73.7%，低過 80% 門檻；目錄合計 86.9%
- 方案 A（推薦）：
    - stub `HTMLCanvasElement.prototype.getContext`，返一個假 ctx（`drawImage` noop、`getImageData` 返已知 pattern），驗四邊 gradient 同座標
    - 再寫一個 case：`getImageData` throw → 返 null（配合 W-458）
    - stub `Image` 觸發 `onerror` → null，同埋第二次 call 唔會再 new Image
    - `renderHook(useBannerEdges)` 換 src 之後即刻返 null
- 方案 B：將 canvas 讀取抽做一個可以注入嘅 `readPixels(img, rect)`，test 直接注入
    - Trade-off：多一層抽象，但 test 唔使 stub DOM

#### 🟢 S-483 — `pressRef` 可能會留住

```ts
/** 用 canvas 讀橫額四邊嘅邊色；讀唔到（jsdom、冇 2d context、canvas 被 taint / decode 失敗）就 null */
export const readBannerEdges = (img: HTMLImageElement): BannerEdges | null => {
    const { naturalWidth: width, naturalHeight: height } = img; // S-486
    if (width === 0 || height === 0) return null;
    const canvas = document.createElement('canvas');
    canvas.width = width;
    canvas.height = height;
    const ctx = canvas.getContext('2d', { willReadFrequently: true });
    if (!ctx) return null;
    try {
        ctx.drawImage(img, 0, 0);
        return edgesFrom(ctx, width, height); // 原本 return 嗰舊抽出嚟，保持函數 ≤ 30 行
    } catch {
        // W-458：SecurityError / decode 失敗唔好令 promise 永遠 pending，邊位用格底色
        return null;
    }
};
```

```ts
/** 每張卡嘅掣屬性：撳 focus 卡 / 鍵盤 → open；撳暗咗嘅卡 → 捲佢做 focus */
const tileHandlers = (
    index: number,
    focus: number,
    pressRef: MutableRefObject<number | null>,
    focusTile: (index: number) => void,
    onOpen: () => void,
) => ({
    'data-focused': index === focus ? '' : undefined,
    onPointerDown: () => (pressRef.current = focus),
    onPointerCancel: () => (pressRef.current = null),
    onPointerLeave: () => (pressRef.current = null), // S-483
    onFocus: () => pressRef.current === null && focusTile(index),
    onClick: (event: MouseEvent) => {
        const focusAtPress = pressRef.current ?? focus;
        pressRef.current = null;
        const keyboard = event.detail === 0;
        if (tapAction({ index, focusAtPress, keyboard }) === 'open') onOpen();
        else focusTile(index);
    },
});
// useShelfFocus 入面：const tileProps = (i, onOpen) => tileHandlers(i, focus, pressRef, focusTile, onOpen);
```
