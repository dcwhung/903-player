## Section A — Mini player 細碟自轉（393×793 直版、844×390 打橫）

- Verdict：✅ pass，兩個 viewport 結果一樣
- 量法：讀 `getComputedStyle(face).rotate`。keyframe 用 `rotate` 屬性，唔係 `transform`，所以讀 `transform` 會得 0
- 未播：`animation-play-state: paused`，0°，冇 `spinning` class
- 撳 ▶：`running`，1.5 秒由 17.3° 轉到 84.7°（+67.4°）。8 秒一圈，1.5 秒應該約 67.5°，啱
- 撳 ⏸：停喺原位，等 2 秒之後 93.7° → 93.7°（打橫 91.5° → 91.5°），**冇彈返 0°**
- 再撳 ▶：由 93.7° 繼續轉去 105.8°，冇由 0° 重新開始
- 冇 page error
- 截圖：`qa14-mini-spin-393×793.png`、`qa14-mini-spin-844×390.png`

## Edge case 評估（主動補測）

1. **暫停之後停喺原位、再播由原位繼續**：pass（Section A）
2. **減少動畫**：pass（Section B）
3. **其他用 `Disc` 嘅地方會唔會被 selector 搬動影響**：清單、GhostCard、TodayEmpty 全部唔轉（Section D）
4. **Audio 載入 / 斷流（播放意圖 = 播，但未出聲）**：❗ 唔一致，見 CUI-0005
    - 情況：route 令 audio 永遠唔回應，mini player 個掣已經變咗「暫停」
    - mini player 細碟：`running`，一直轉（111.7°）
    - 大碟：用 `isAudible` 而且 upright，所以停喺 0°
    - 原因：`MiniPlayerRow` 傳嘅係 `isPlaying`（意圖），但 `Disc` 個 `spinning` prop 文檔寫明「真正出緊聲先轉；載緊停喺原位」
    - 純視覺，評 🟢
5. **由節目頁返主頁**：mini player 係重新 mount，角度由新開始（例如 111.7° → 53.2°）。呢個係正常 React 行為，大碟由主頁入節目頁都係一樣，唔當問題
