## Section A — 書架捽 focus（唔使捲模式，4 套劇）

- Verdict：✅ pass（393×793 同 390×844 都試咗）
- 書架冇 `data-scroll`，`touch-action` 係 `pinch-zoom`
    - CSS 寫咗 `none` 再寫 `pinch-zoom`，Chromium 用後面嗰個，即係雙指放大冇擋
    - Chromium 模擬唔到真 pinch，所以只驗咗 computed style
- **向下捽再向上捽**：手指由卡 0 拖落卡 3，再拖返上卡 1，每一步都記低 focus：`[0, 1, 2, 3, 2, 1]`，每張卡都跟足手指
- **放手**：
    - 留喺主頁（`#/`），focus 停喺 1，scrollTop 0
    - document 連 click event 都冇收到，即係唔會打開劇集
    - 之後撳 focus 卡（1）→ 打開 `#/drama/sammy-kitty`
- **普通撳暗卡 2** → focus 2，唔會 navigate
- **郁少過 8px 當係撳**：
    - 暗卡 3 郁 5px → focus 3，唔會 navigate
    - focus 卡 3 郁 6px → 打開 `#/drama/chisee`
- **郁超過 8px 當係捽**：
    - 由卡 0 去暗卡 1 郁 10px → focus 0 → 1，唔會 navigate
    - 喺 focus 卡範圍入面郁 12px → 都**唔會打開**，即係捽完個 click 被食咗
- **鍵盤**：喺「廣播劇」tab 撳 Tab 兩下 → 卡 1 攞到 focus，`data-focused` 跟住；Enter → 打開 `#/drama/sammy-kitty`

    - ShowCardStack 有先例，用 `-webkit-user-drag: none`
    - 手指 / pen 冇呢個問題。不過 iOS 長按圖片可能都會出拖放預覽或者 callout，要真機確認

## 失敗測試詳情

### `mouse.mjs`：滑鼠撳住拖捽唔到 → CUI-0004（🟢）

- 預期：卡 0 撳住拖去卡 2 → focus 2，之後撳 focus 卡會打開
- 實際：focus 仲係 0；之後嗰下撳中嘅係暗卡，所以淨係轉 focus、冇打開（第 2 個 check 紅係跟住第 1 個嚟）
- 根源：`.art` 圖片冇 `-webkit-user-drag: none`，亦冇 `draggable={false}`，原生拖放觸發 `pointercancel`
- 建議：跟 ShowCardStack 加 `-webkit-user-drag: none`（可以再加 `-webkit-touch-callout: none`），再加 CSS / DOM 測試
