## 失敗測試詳情

### CUI-0012 — 鎖屏慢載途中亮屏被 reload（`f16cc0a` 引入）

- 位置：`src/player/stallWatchdog.ts` `onDeadline()` 前景分支 `if (wanted && this.isStillLoading())`
- 預期：hidden 期間下載仲有進展，亮屏（`visibilitychange → retryIfOverdue → onDeadline`）應該同 W-498 一樣 `arm()` 再等，唔 abort
- 實際：`audio.load` 被叫 1 次，`retry … left=3`
- 根源：W-510 令每個 hidden tick 刷新 `baseline`；W-511 / W-512 只修咗鎖屏 Play 用嘅 `loading` getter（用 `previousBaseline ?? baseline`），前景 `onDeadline` 仍然用最新 `baseline`。hidden tick 啱啱行完（iOS 解凍時過期 timer 同 `visibilitychange` 次序冇保證）→ 比較窗口 ~0 → 當冇進展 → `retryNow()`。即係 W-511 嘅前景版本
- 影響：前景 reload 之後通常播得返（唔係永久壞），但慢網會由頭再下載、扣一次重試，違反 W-498，而且 v1.20.9 唔會咁。窗口：每次嘗試頭 12 s 內，或者 mark tick / `frozenTimer` 啱啱喺亮屏前行
- 建議（已驗證）：

```ts
// stallWatchdog.ts onDeadline()
if (wanted && this.isStillLoading(this.previousBaseline ?? this.baseline)) {
```

`arm()` 會清 `previousBaseline`，純前景 recheck 行為唔變。`8d4442f` scratch copy 加呢一行：`src/player` 271 + QA 11 = 282 全綠
