## 問題描述

用戶要求：短篇劇集頁（例如 `#/drama/chisee`、`#/drama/golden`）未載入時，唱片係**冇圖嘅黑碟，同今日頁「今日冇節目」（TodayEmpty）一樣**。

v1.19.3（`425c4eb`）只係將 `PlayerGauge` 嘅 `art` 改做 `undefined`，拎走咗封面。但係冇圖嘅碟用嘅係 `Disc.module.css` 嘅 `background: var(--color-disc)`，而 `--color-disc` 係 `var(--theme-shadow-dark)`（`src/styles/tokens.css:415`），每個 `[data-theme-scope]` 都會跟節目主題重新解析：

| 頁面                          | `--theme-shadow-dark` | 碟面顏色 |
| ----------------------------- | --------------------- | -------- |
| 今日頁 TodayEmpty（中性主題） | `#0a0a0a`             | 黑       |
| 黃金少年                      | `#e0c77e`             | 金色     |
| 芝See菇Bi Family              | `#e6cc5c`             | 黃色     |

碟邊（`--color-disc-rim` = `--theme-surface`）都一樣跟主題變咗淺色。所以劇集頁見到嘅係一隻金 / 黃色嘅淨色碟，同 TodayEmpty 嗰隻黑碟唔一樣。

jsdom 單元測試只斷言 `.discArea img` 係 `null`（冇圖），冇驗顏色，所以 review 同 unit test 都冇發現。

## 重現步驟

1. 清空 localStorage（呢套劇冇進度），390×844 直版
2. 開 `#/drama/golden`（或 `#/drama/chisee`），全集表彈出，閂咗佢
3. 另一個 tab：今日冇節目嘅時間（例如星期二 09:00 未上架）開 `#/today`，見到 TodayEmpty
4. 比較兩隻唱片

## 預期結果

劇集頁未載入嘅唱片同 TodayEmpty 一樣：黑色碟面（`#0a0a0a`）+ 深灰碟邊，冇圖。頁面其他主題色（背景、標題、強調色、弧形）不變。

## 影響範圍

- **受影響功能**：短篇劇集頁唱片（第一次入未揀短篇；播緊其他嘢）。直版、橫版都係
- **唔受影響**：載入咗之後嘅封面、mini player、主題色

## 解決方案建議

- 冇圖嘅播放器唱片固定用中性色，唔跟頁面主題。例如喺 `PlayerGauge` / `Disc` 冇 `art` 時加一個 modifier（例如 `.blank`），入面覆寫 `--color-disc` / `--color-disc-rim` 做中性主題嘅值（`NEUTRAL_THEME.shadowDark` `#0a0a0a`、`NEUTRAL_THEME.surface` `#1e1e1e`），或者直接用新 token（例如 `--color-disc-blank`），唔好寫死 hex（見 `sw-coding-style-css`）
- 要確認 TodayEmpty 嘅 ring / 碟邊都係同一組中性值，令兩隻碟一模一樣
- 注意唔好改頁面 `ThemeScope` 嘅變數（用戶要求主題色不變）
- 測試：jsdom 量唔到 computed 顏色。建議加 node CSS test 鎖住 blank modifier 用中性 token，同埋 e2e 量 `getComputedStyle(disc).backgroundColor` 喺劇集頁未載入時等於 TodayEmpty
