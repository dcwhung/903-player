## 問題描述

`f01f02e` 為 S-1117 喺 `ItemInfoSheet.module.css` 加咗 `DUO_LANDSCAPE_QUERY` 區塊，但淨係將 `.docked` 嘅 `bottom` 伸出 `--duo-edge-inset`。節目資料表喺右欄，右邊照舊俾 ThemeScope `.scope` 嘅 8px padding 推入，橫額同圓角離畫面右邊 8px。現有手機打橫（844×390）同一張表右邊係 0。

## 重現步驟

1. `npm run build -- --mode e2e`，vite preview
2. Remote catalog 畀公子會加簡介（同 `e2e/itemInfo.mjs` 示範 catalog），viewport 612×426（或 612×438、876×612）
3. 開 `#/show/gongzi`，第一次入自動彈「節目資料」dialog，量 `boundingBox`

## 預期結果

右邊同底邊都貼畫面邊：612×426 / 612×438 右邊 0；876×612 右邊同闊橫版對照（1000×562）一樣 30（把手預留位，由畫面邊計）

## 實際結果

```
闔上・橫 612×426  sheetBottomGap 0  sheetRightGap 8
Seated   612×438  sheetBottomGap 0  sheetRightGap 8
打開・橫 876×612  sheetBottomGap 0  sheetRightGap 38
對照 844×390      sheetBottomGap 0  sheetRightGap 0
對照 1000×562     sheetBottomGap 0  sheetRightGap 30
```

## 環境

- **測試環境**：local vite preview（`--mode e2e` build of `f01f02e`），Chromium `/opt/pw-browsers/chromium`
- **相關版本**：`f01f02e`

## 影響範圍

- **受影響功能**：節目頁 / 今日節目 / 廣播劇頁嘅 docked 資料表（Duo 闔上・橫、Standing、Seated、打開・橫）
- **受影響用戶**：只限 iPhone Duo 打橫姿勢；現有裝置唔受影響

## 建議修法

`ItemInfoSheet.module.css` Duo 區塊加 `right: calc(-1 * var(--duo-edge-inset));`（打開・橫要確認把手預留位仍然由畫面邊計），`e2e/duo.mjs` 加「資料表貼右邊同底邊」斷言。

## 驗證方式

`e2e/duo.mjs` 新斷言 + `npm run e2e:visual` 對 base 180/180 一樣；QA 重驗 drama / show-today-page S1 後 freeze。
