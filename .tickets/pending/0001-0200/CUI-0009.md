## 問題描述

`e2e/run.mjs` 嘅 `checkPoppinsLoaded` 註解寫「冇 @font-face 或者字型檔 404 就係空 / 唔係 loaded」，即係預期 404 會變成一行 `FAIL`。實際上 CSS Font Loading API 規定：`document.fonts.load()` 只要有一個 matching face 載入失敗就 **reject**（`NetworkError`），唔係 resolve 一個 `status: 'error'` 嘅 face。`p.evaluate` 冇 catch，所以成個 `run.mjs` 拋 uncaught exception：

```text
PASS  390×844 主頁：版本號 v1.20.6 喺橫額右下角（321, 89）
node:internal/modules/run_main:123
    triggerUncaughtException(
page.evaluate: NetworkError: A network error occurred.
    at checkPoppinsLoaded (…/e2e/run.mjs:112:28)
```

- 只跑咗 11 個 check（正常 590），冇「N E2E check(s) failed」總結，錯誤訊息冇講 Poppins
- `finally` 照樣閂 browser + preview server（port 冇殘留），exit code 1，所以 **唔會假 pass**
- 對照：CSS 答空（冇 `@font-face`）時 `load()` resolve `[]`，check 正常印 `FAIL … （冇：400 / 500 / 600）`，呢條路冇問題

觸發場景：`@fontsource/poppins` 升級改咗檔名、`files/` 路徑變、某個字重檔唔見（例如 S-577 講嘅字重 index.html 改咗），或者 responder 改壞。

## 重現步驟

1. 抄 repo 去 scratch（`node_modules` symlink 返）
2. `e2e/harness.mjs` `fontFilesResponder` 第一句改成一律 `return route.fulfill({ status: 404, body: '' })`
3. `E2E_PORT=4199 npm run e2e`

## 預期結果

`FAIL  390×844 主頁：Poppins 400 / 500 / 600 都載入咗（冇：400 / 500 / 600）`，其餘 check 照跑，最尾「1 E2E check(s) failed」。

## 實際結果

11 個 PASS 之後 uncaught `NetworkError`，冇 FAIL 行、冇總結。

## 解決方案建議

- `checkPoppinsLoaded` 每個字重 `document.fonts.load(...)` 包 `.catch(() => [])`（或者 try/catch），reject 當冇載入，照行 `document.fonts.check`
- 改返註解：「字型檔 404 → `load()` reject」
- 可以順手做 S-577 建議：unit test 鎖 index.html 嘅 Poppins 字重有對應 fontsource CSS / woff2

## 驗證方式

QA 照重現步驟重跑：見到 Poppins check 嘅 `FAIL` 行、其餘 check 照跑、最尾有失敗總結、exit 1；正常 / 離線各跑一次 590 PASS。
