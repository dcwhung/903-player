## 問題描述

呢個 test 用 TypeScript API 建成個 `tsconfig.node.json` program（單獨 1.3–1.4 s），冇明確 timeout，用 vitest 預設 5 s。

QA `npx vitest run --coverage`（158 files 平行、v8 coverage instrument）：

```text
× should not give Node-run scripts vite/client types (import.meta.env) 7560ms
Error: Test timed out in 5000ms.
 Test Files  1 failed | 157 passed (158)
      Tests  1 failed | 1953 passed (1954)
```

同一 commit 即刻再跑：`npx vitest run`（冇 coverage）158 files / 1954 tests 全綠；單獨跑個檔 78 / 78 綠（3.8 s）。

## 影響

- 冇產品影響（呢個 test 驗證 tsconfig 分工，S-567）
- 全 suite 偶然紅，會令 QA / CI gate 誤判；program 會隨 `scripts/`、`tests/` 增長而再慢

## 解決方案建議

- 方案 A（推薦，即 S-574 方案 A）：`it(..., () => {...}, TYPECHECK_TIMEOUT_MS)`（例如 `20_000`，具名常數），註解寫明係 TypeScript 建 program
- 方案 B：只建 probe + 必要檔案嘅細 program：快好多，但會漏「其他檔 triple-slash reference」，S-574 已經講明唔建議

## 驗證方式

- 呢個 test 嘅斷言冇改（mutation：`tsconfig.node.json` 加返 `vite/client` 仍然紅）
