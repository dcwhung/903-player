## 根源分析

1. `e2e/run.mjs:1445-1448`（390×844 主流程）：`節目表 li button` 而家每行有 ▶ 同 ☆ 兩粒掣（AC-1），數到 6 個唔係 3 個。
2. `e2e/run.mjs:619-624` `checkSwipeToOlder`：`集數 li button` 嘅 `labels[from + 1]` 而家係「收藏 19/10 星期一」，`replace(/^(播放|暫停) /)` 去唔走「收藏」→ `dayOffset` 搵 `轉去 收藏` → `boundingBox` timeout，成個 section 中止。
3. `e2e/bookmark.mjs:102`：`new URL(p.url()).hash === '#/'`，但主頁 URL 係 `http://…/903-player/`，hash 係 `""`（本機 Playwright 實測：`goto base` 之後 `hash= ""`）。同一個 section 嘅「播緊嗰行掣變 ⏸」PASS，即係仍然喺主頁收藏 tab，產品冇問題。

## 解決方案建議

- 1、2：只揀播放掣，例如 `li button:not([aria-pressed])`、或者 `getByRole('button', { name: /^(播放|暫停) / })`，唔好數 / 讀 ☆ 掣
- 3：斷言改做 hash 係 `''` 或 `'#/'`（例如 `['', HOME_HASH].includes(hash)`），或者改驗 `region 我的收藏` 仲見到
- 改完本機跑一次 `npm run e2e`，確認「節目頁 / 今日節目頁尺寸」所有 viewport 都跑到（集數行多咗 ☆ 之後嘅尺寸 check 要綠）
