## 問題描述

`--out` 嘅上層 folder 唔存在（例如打錯字、路徑有空格冇包引號以外嘅錯），或者 `--out` 本身係一個 folder，`writeFileSync` throw `ENOENT` / `EISDIR`，由 `run` 嘅 catch-all 接住，當成 `EXIT.internal`：

```text
程式出錯：ENOENT: no such file or directory, open '…/qa-dff/nope/x.json'
呢個唔係 folder 嘅問題；請將成段輸出（連下面嘅技術資料）傳返嚟。

技術資料：
Error: ENOENT: no such file or directory, open '…/qa-dff/nope/x.json'
    at writeFileSync (node:fs:2437:20)
    at generateAndWrite (file:///…/dramaFromFolder.mjs:1007:5)
    …
```

README exit code 表寫 `4` =「程式出錯（唔係 folder 問題）：請將成段輸出傳返嚟」，`2` =「參數錯」。呢個係參數錯，應該 exit `2` 兼講點改；而且喺生成之前就驗得到（同 S-568 嘅 `--report` 一樣）。

## 重現步驟

1. 淨係下載 `dramaFromFolder.mjs` 落一個空 folder
2. `node dramaFromFolder.mjs "<任何合格劇集 folder>" --id qa-series --out "/路徑/唔存在/x.json"`
3. 或者 `node dramaFromFolder.mjs "<劇集 folder>" --id qa-series --out "/一個已有嘅 folder" --force`

## 預期結果

一開始（掃 folder 之前）就話 `--out` 嘅 folder 唔存在 / `--out` 係 folder，exit `2`，冇 stack trace。

## 實際結果

成份報告印完先出「程式出錯」+ stack trace，exit `4`（兩個情況都係）。冇寫任何檔（正確）。
