## 根源分析

- `e2e/run.mjs:1381-1382`：`click()` 之後即刻 `log(page.url().endsWith('#/'), '返回主頁')`
- 主流程係撳格仔入節目頁（有 zoom 來源）→ 窄版返回行 `unzoomHome(zoomFrom, go)`（`src/hooks/useGoHome.ts`），`navigate('/')` 喺 `startViewTransition` 嘅 update callback 先行（瀏覽器影完舊畫面之後，晚一格）
- 以前窄版返回係同步 `go()`，所以個斷言一直過；而家要等

## 解決方案建議

只改 e2e，唔使改 src：

```js
await page.getByRole('button', { name: '返回主頁' }).click();
const home = await succeeds(page.waitForURL((u) => u.hash === '#/', { timeout: 5000 }));
log(home, '返回主頁');
```

（`succeeds` 喺 `e2e/harness.mjs`。）順手睇下 `e2e/run.mjs:1418` 同其他「撳返回後即刻讀 DOM / URL」嘅地方（1418 有 `waitForTimeout(300)`，今次過咗）。
