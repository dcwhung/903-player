## 問題描述

一套劇同時有「繼續收聽」條 + 左上角快將下架琥珀字 + 即將上架短篇（H2 字尾），右上角短篇數 pill 被 ellipsis 截到淨係「3」/「3.」。

- 重現：`npm run build -- --mode e2e` + preview；context 加 `903player:e2e:dramas` flag，progress 寫 `初戀無限次` 第 2 集（同 `e2e/comingSoon.mjs` `seedStorage`），時鐘 E2E_NOW（30/11 22:30），開主頁「廣播劇」tab，睇「E2E 即將劇場」格
- 量度（短篇數 span `clientWidth / scrollWidth`）：844×390 **16/147**、1300×800 **28/220**（格闊 249px）；390×844 147/147 正常
- 格嘅讀屏名「E2E 即將劇場，部分短篇 19/12（六）下架」冇上架資訊（字尾 span `aria-hidden`，見 review S-700）

## 根源分析

`src/components/pages/home/DramaShelf/DramaShelf.module.css:189-211` `.topBar`：左上角 `.corner` `flex-shrink: 0`，右上角 `.meta` `min-width: 0` + ellipsis。左上角「⏳ 部分短篇 19/12 下架」佔晒頂行，H2 字尾（`DramaTile.tsx:15`）冇位。

## 解決方案建議（由用戶 / developer 揀）

- (a) 有續聽 + 左上角有字時，字尾移去續聽條上面 / 另一行
- (b) 頂行放唔落只截「N 個短篇」部分，保留「新短篇 X 上架」
- (c) 上架字加入 tile `aria-label`（亦解 S-700）
