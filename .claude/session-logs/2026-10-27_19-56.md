## Shared Knowledge 更新

無（以下兩點係呢個項目嘅經驗，下次 audit 可以考慮寫入 SK）：

- `react-hooks/refs`（React compiler lint）唔准喺 render 時將 `useRef` 或者名叫 `*Ref` 嘅值傳入 factory、喺 render 讀佢，亦唔准 mutate `useState` 嘅值；可行做法係 `useBox` 加 callback ref，並將 box 本身傳落去。
- 用 Python 字串替換改 code 之前要先睇最新內容：Prettier 會將長 selector / import / 參數拆做幾行，令字串對唔到。
