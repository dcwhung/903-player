試吓：左右掃轉節目；長按 0.5 秒浮起之後左滑關閉
  • 平時左右掃（≥ 48px）照舊轉今日節目，循環轉
  • 手指唔郁長按 0.5 秒 → card 浮起（大少少 + 陰影深啲）
  • 浮起之後副題換做「‹‹ 滑動關閉」；向左拉：card 跟手指走，右邊露出深藍「⏻ 關閉」（同一下唔放手拉，或者放手再拉都得）
  • 拉過 card 闊度一半放手 → 直接關閉（停播 + 收起）
  • 拉咗少少（≥ 40px）放手 → 停喺度露出「關閉」掣，撳先關閉；撳 card / 外面 / 向右拉 → 收返
  • 浮起咗 4 秒冇郁 → 變返平時（左右掃又係轉節目）
  • 長按 / 拉嘅時候唔會觸發開節目頁、播放 / 暫停（click 食咗）
  • 讀屏 / 鍵盤：加一粒讀屏先見到嘅「關閉播放器」掣，唔使做手勢
  • 廣播劇 mini player（得一集）都係同一套：長按 → 左滑關閉
